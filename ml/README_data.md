# Dataset Versioning and Data Provenance

## Dataset Overview
- Dataset path: `data/waste.csv`
- Dataset format: CSV
- Input features: `weight_g`, `moisture_pct`, `magnetic`
- Target column: `category`
- Valid categories: `plastic`, `metal`, `paper`, `organic`
- DVC tracking file: `data/waste.csv.dvc`
- The raw `data/waste.csv` is NOT committed to Git (see `data/.gitignore`); it is versioned by DVC.

## Data Source
The project uses the local dataset at `data/waste.csv`.
- v1: raw dataset, 32 rows (8 samples per category).
- v2: generated by `ml/make_v2_dataset.py` — cleaned (deduplicated) and
  augmented (each category expanded to 16 samples by sampling + small
  Gaussian noise on numeric features), 64 rows total.

## Dataset Versions

## DVC and Remote Storage
- DVC tracks `data/waste.csv` via `data/waste.csv.dvc`.
- Azure remote: `azure://dvc/smart-waste-classifier/` (remote name `myazure`).
- Storage account: `wut2026`; authentication via SAS token stored in the
  git-ignored local config `.dvc/config.local`. No credentials are committed to Git.
- Both v1 and v2 have been pushed to the Azure remote with `dvc push`.
- Version restore verified: `dvc checkout` on the v1 commit restores 32 rows;
  on the v2 commit restores 64 rows.
